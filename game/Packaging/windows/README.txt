DETH for Windows (portable)
===========================

The game and its settings stay in this folder; move or copy it anywhere.
Your characters are saved in Downloads\DETH\saves, so they survive
deleting this folder and are easy to copy to another device.

Play
  Run DETH.exe. The free shareware version is built in.

Full game
  Main menu > Import Game Files: pick DIABDAT.MPQ, a folder, an archive (zip, 7z, rar, tar.gz,
  also password protected) or GOG's offline installer. Or copy DIABDAT.MPQ from your copy of
  Diablo (CD, GOG or Battle.net) into this folder.
  Hellfire: also hellfire.mpq, hfmonk.mpq, hfmusic.mpq and hfvoice.mpq.
  The tools folder holds 7-Zip and innoextract, which Import Game Files uses.

Controllers
  Xbox-style layout out of the box; every button can be changed under Settings > Gamepad Mapping.

Updates
  Main menu > Check for Updates downloads and installs new versions in place.
  Settings > Start Up > Update Channel: Stable, or Beta for test versions.

Remove
  Delete the folder.
